# SkyCast | Modern Weather Dashboard 🌤️

SkyCast is a premium, single-page weather application that provides real-time weather updates for any city worldwide. It features a clean, modern interface with glassmorphism aesthetics and dynamic data fetching.

### 🌟 Key Features
*   **Live Weather Data:** Get instant updates on temperature, humidity, wind speed, and pressure.
*   **Geolocation Support:** Automatically detect your current location to show local weather.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.
*   **Dynamic Visuals:** Weather icons update based on real-time atmospheric conditions.
*   **User-Friendly Search:** Quick search functionality with "Enter" key support.

### 🛠️ Built With
*   **HTML5:** Semantic structure.
*   **CSS3:** Custom styles with Glassmorphism effects and smooth transitions.
*   **JavaScript (ES6):** Asynchronous API integration and DOM manipulation.
*   **OpenWeatherMap API:** Global weather data source.
